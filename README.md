ARM Assembly Array Processing Program

This project is written in ARM Assembly using the Thumb instruction set,the program processes an array of numbers and performs 
multiple operations such as calculating the total sum, calculating the sum of even numbers, and finding the largest power-of-2 
divisor for each element.

 Features
- Calculate total sum of array elements
- Calculate sum of even numbers
- Find largest power-of-2 divisor
- Store results in memory

 Array
34, 56, 27, 156, 200, 68, 128, 235, 17, 45

Concepts Used
- ARM Thumb Instructions
- Bitwise Operations
- Loops and Branching
- Memory Access
- Procedures/Subroutines
